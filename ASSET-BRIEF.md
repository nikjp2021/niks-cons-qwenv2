## Image Optimization Notes

- **Format:** WebP for all raster images (30% smaller than JPEG at same quality)
- **Responsive:** Serve multiple sizes via `srcset` (640w, 1024w, 1920w)
- **Lazy loading:** All images below fold use `loading="lazy"`
- **Alt text:** Every image has descriptive alt text (see content.md for specifics)
- **Placeholder:** Use blurred LQIP (Low Quality Image Placeholder) while loading
- **Dark mode:** Hero backgrounds designed for dark surfaces; no light-mode variants needed (gradients are subtle enough for both)
